# Mobile App Automation Testing with Appium + Robot Framework

Part of my QA Automation Portfolio 
This repository contains **two automation case studies** using Appium and Robot Framework on Android applications.

---

## Case Study 1: Demo App Automation

### Objective
Create automated test scripts for the Demo App covering:
- Button click navigation
- Page transition verification

### Tools & Stack
- Robot Framework  
- Appium Library  
- Android Emulator / Real Device  

---

## Case Study 2: Diet Meal App Automation

### Objective
Automate user data input and calculation flow for the Diet Meal app using **data-driven testing (DDT)** approach.

### Tools & Stack
- Robot Framework  
- Appium Library  
- Python 3.11  
- Android Emulator or Physical Device  

### Test Scenarios
| Scenario | Description |
|-----------|-------------|
| 1 | Launch app |
| 2 | Input user data from CSV (Name, Weight, Height) |
| 3 | Submit form |
